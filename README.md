# Myagmarsuren Portfolio

Personal portfolio of Myagmarsuren Erdenebayar, Full-Stack Developer.

**Website:** https://myagmarsuren.vercel.app/

## Features

- Day and night themes, with a rotating Moon and interactive solar system
- English and Mongolian interface
- Horizontal project galleries: My Own Projects and Team Projects
- GitHub contributions and live Ulaanbaatar weather and time
- Contact information and a PDF resume

## Preview locally

This is a buildless static website. From this folder, run:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open http://127.0.0.1:4173/.

## Deployment

Vercel project: `myagmarsuren`. Serve the repository root with the Other framework preset; no installation or build step is needed. Pushes to the repository’s production branch are deployed automatically once Git integration is connected.

The resume is stored at `assets/resume/myagmarsuren-resume-mn.pdf`.
